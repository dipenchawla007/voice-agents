Voice Agent Widget Demo

About the Widget

This demo shows how to integrate the Voice Agent Widget into your website. The widget allows your visitors to interact with AI-powered voice agents through their microphone.

How to Integrate

Simply add the following script tag to your website: 

<script 
    src="https://your-domain.com/static/voice-agent-widget.js" 
    data-company-id="YOUR_COMPANY_ID" 
    data-agent-id="YOUR_AGENT_ID">
</script>

Replace YOUR_COMPANY_ID and YOUR_AGENT_ID with your actual IDs.

Customization Options

You can customize the widget using these data attributes:

  • data-company-id - Your company ID (required)
  • data-agent-id - Your agent ID (required)
  • data-theme - Widget theme: "light" or "dark" (default: "light")
  • data-position - Widget position: "bottom-right" or "bottom-left" (default: "bottom-right")
